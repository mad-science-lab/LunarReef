# Changelog

## 0.1.0
- Makes the lunar channel of EcoTech Radion XR15 lights (Neptune MXM module) follow
  the real moon at your location.
- Settings page served through Home Assistant Ingress, with a map location picker.
- Daily update runs in the container on HA's timezone and catches up after a restart.
- Installable from GitHub as a Home Assistant add-on repository, or run standalone.
