# ApexLunar add-on

Makes the lunar (moonlight) channel of EcoTech Radion XR15 lights on a Neptune
Apex (MXM module) follow the real moon at your location.

Open **ApexLunar** in the Home Assistant sidebar. On first start the location is
Home Assistant's home; set the Apex address, login and lunar output there, then
**Preview** and **Apply to Apex**. The daily update runs inside the add-on at the
time shown under *Daily update* (Home Assistant's timezone) and catches up if the
add-on was stopped.

Settings, backups and the activity log are kept in the add-on's own storage and
are included in Home Assistant backups.
